# Hot6ix Domain

## 서비스

Hot6ix는 SNS 라이브 방송과 함께 쓰는 링크 기반 실시간 경매 서비스다.
판매자는 프로필·상품·경매방을 준비하고 링크/QR을 공유한다.
사용자는 비로그인으로 방을 조회하고, 로그인 후 참여·입찰한다.

최소 흐름:

`로그인 → 판매자 프로필 → 상품 → 경매방 → 물품 추가 → 참여 → 시작 → 입찰 → 현재가 반영 → 마감 → 낙찰 후보`

## 도메인

- 회원·인증: 가입, 로그인, 휴대폰 인증, 내 정보, 탈퇴
- 판매자·상품: 프로필과 경매용 상품 CRUD
- 경매방·물품: 생성, 공유, 추가/제외, 최대 3개 병렬 진행
- 입찰: 참여·권한·현재가·단위·마감 검증과 동시성 제어
- 실시간: 방/물품 상태, 현재가, 리더보드, 연장, 마감 전달
- 이력·낙찰: 기록, 후보, 차순위, 결과

## 핵심 정책

- 비로그인 조회는 허용하되 입찰은 인증이 필요하다.
- 시작·마감·Soft Close는 서버 시간을 기준으로 한다.
- 입찰은 해당 물품에만 영향을 준다.
- 마감 후 입찰, 현재가 이하, 단위 불일치, 중복 요청, 무권한 입찰을 거절한다.
- 결제, 배송 추적, 자체 라이브 스트리밍은 MVP 밖이다.
- DB가 입찰·상태·낙찰의 원본이다.

## 소유 경계

- 회원·로그인 상태: 인증 영역
- 판매자·상품·경매방·물품 생명주기: 운영 영역
- 현재가·최고 입찰자·입찰 이력: 입찰 영역
- 상태 기록·낙찰 후보·결과: 이력/낙찰 영역
- 실시간 화면과 요청 제한: 실시간/최적화 영역

경계가 모호하면 공동 구현보다 원본 책임자와 계약을 먼저 정한다.
